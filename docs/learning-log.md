# 학습 기록

자체 검증과 대조를 반복하며 무엇을 배웠고 무엇을 고쳤는지 적어요. 최신 기록이 위에 있어요.
평가 보고서는 `docs/evals/`, 조사 내용은 `docs/research/`에 있어요.

## 평가 방법
- **시나리오**: `tests/scenarios/*.json`. 촬영 가이드대로 찍었다고 가정한 "분석 결과"(가상 가게, 실제 아님). 사진 없이 글쓰기·검증만 시험해요.
- **실행**: `node scripts/eval-scenario.js restaurant festival park`
- **채점**: AI 편집장(`content-review` 스킬)이 6개 항목(사실, 첫인상, 사람다움, 플랫폼, 정보, 구체성) 1~5점 + 규칙 검사(`src/pipeline/lint.js`)
- **자동 보완**: 기준 미달(총점 4.3 미만, 한 항목이라도 3점 이하, 규칙 오류, 짧은 영상 길이 초과)만 다시 씀

## 2회차: 맛집·축제·공원 (평균 4.51 / 4.19 / 4.37)

| 시나리오 | 평균 | 사실 3점 이하 | 자동 보완 |
|---|---|---|---|
| 맛집 | **4.51** (1회차 4.43) | 0개 (1회차 2개) | 쓰레드, 블로그 |
| 축제 | 4.19 | 3개 | 6개 |
| 공원 | 4.37 | 4개 | 4개 |

맛집은 1회차에서 고친 규칙 덕분에 사실 점수가 거의 다 5점이 됐어요. 축제·공원에서 새로운 실수가 나왔어요.

**배운 것 → 고친 것**
1. **날짜 감각이 없다**: 축제가 11/15에 끝났는데(오늘 11/17) "15일까지니까 지금 가세요"라고 씀 → 대본 쓸 때 **오늘 날짜**를 함께 주고, 끝난 기간이면 회고형(내년 참고용)으로 쓰게 함.
2. **위치·동선을 지어낸다**: "메타세쿼이아길 지나면 수변 데크", "입구 쪽 지도" → 지도·안내판에 없는 위치·순서 금지.
3. **강도를 키우고 조건을 뒤집는다**: 메모 "사람 많음" → "엄청 많음", 메모 "10시 이후 만차" → "10시 전에 만차", 역광/순광 착각 → 메모의 세기·방향 그대로, 상식 추정(일몰 시각 등) 금지.
4. **한 번 간 걸 일반화**: "평일에도 줄 서는 곳" → "제가 간 날은 평일인데도 줄".
5. **영상 나레이션이 여전히 길다** → 장면당 30자 이내(핵심 1~2개만 45자) 규칙 + 규칙 검사 추가.
6. **가격 표시가 길다**("어묵 3,000원·닭꼬치 4,000원·회오리 5,000원") → 14자, 가격 하나만.
7. **장면과 나레이션이 따로 논다** → "그 장면에 보이는 것을 말한다" 규칙.
8. **해시태그에 장소 이름이 없다** → 규칙 + 검사 추가.
9. **블로그가 짧다**(공백 제외 1,100자) → 지어내지 않고 채우는 법: 장면에 보이는 사실을 묘사, 대표 메뉴는 두 섹션으로.
10. **말끝이 단조롭다**("~어요" 9번 연속) → 규칙 검사 개선(평범한 "~요" 6문장 연속이면 경고).

**외부 글과 직접 대조한 시도**: 네이버 블로그는 자동 수집을 막아 둬서(접근 거부) 직접 읽지 못했어요. 다른 블로그 플랫폼도 429/403으로 막혔어요. 대신 검색 요약에서 확인된 실제 후기 구조(축제: 기본정보 표 → 일정 → 주차·셔틀·막차 → 프로그램 동선 → 공식 링크)를 카테고리 작성법에 반영했어요. 직접 대조하려면 참고하고 싶은 글을 텍스트로 붙여 주시면 돼요.

## 1회차: 맛집 시나리오 (평균 4.43 / 5)

| 결과물 | 총점 | 약점 |
|---|---|---|
| 쇼츠 | 4.6 | 길이 53초 (권장 45초), 훅과 첫 나레이션 반복 |
| 릴스 | 4.3 | 쇼츠와 훅·장면 순서가 거의 같음 (플랫폼 3점) |
| 틱톡 | 4.3 → 보완 | 메모에 없는 감상 ("난 그게 좋았어") 사실 3점 |
| 롱폼 | 4.4 | 지어낸 조언 ("12시 전에 가보세요"), 같은 표현 3번 반복 |
| 캐러셀 | 4.6 | 표지 문구 모호 |
| 쓰레드 | 4.7 | 마지막 문단이 정보 나열 |
| 블로그 | 4.1 → 보완 | 지어낸 경험 6군데, 본문 짧음 (1,094자) |

**배운 것 → 고친 것**
1. **"내 경험처럼 쓰라"는 규칙이 지어내기를 부른다** → `humanize-korean`에 "감상·평가·행동은 메모에 있는 것만" + 금지 예시(지어낸 감상·조언·추정)와 바꾸는 법 추가.
2. **동시에 쓰면 쇼츠·릴스·틱톡이 서로 닮는다** → 두 단계로 쓰기: ① 쇼츠·롱폼·블로그·쓰레드 ② 릴스·틱톡·캐러셀은 쇼츠의 훅·장면 순서를 보고 "겹치지 않게".
3. **영상이 길어진다** → 스킬에 나레이션 글자 예산 (쇼츠 120~230자, 릴스 60~150자, 틱톡 100~220자).
4. **화면 훅이 문장이 된다** → 훅은 한 줄 12자(롱폼 16자), 최대 2줄로 명시.
5. **자동 보완 기준이 느슨했다** (릴스 플랫폼 3점인데 통과) → 총점 4.3 미만 또는 한 항목이라도 3점 이하면 보완.
6. (시험 환경) 예전 수정 요청이 채점에 섞임 → 평가 실행 때는 수정 기록 제외(`NO_FEEDBACK`).

블로그는 자동 보완 후 자연스러운 글이 됐어요: 방문 계기 → 메뉴판 → 기본 반찬 → 대표 메뉴 → 수육 → 아쉬운 점 → 방문 정보 + Q&A.
