## 공통점 → 우리 지침과의 차이
1. **사진이 많다**: 보통 15~30장(공원·팝업은 40장 이상), 사진 1장당 글 75~125자. 우리는 섹션마다 1장(5~9장)이었음 → **섹션마다 사진을 더 넣고(extra_shots) 문단 사이에 배치**.
2. **한 줄이 짧다**: 한 줄 평균 12~14자, 줄의 80~90%가 22자 이하 (모바일 한 줄 = 한 문장). 우리는 "2~3문장마다 빈 줄" → **한 줄에 한 문장, 긴 문장은 쉼표에서 나눔**.
3. **제목은 40자 안팎 + 부제**: 앞에 지역·역 + 업종 + 장소명, `｜` 뒤로 웨이팅·주차·가격 같은 실용 정보. 단풍·축제는 방문 날짜("11월 13일 방문", "실시간"), 목록형은 "BEST 5". "내돈내산·솔직후기"가 자주 붙음. 우리는 32자 이내 → **40자 안팎, 앞 25자에 검색어**.
4. **컨셉별 1순위 정보**: 공원·축제·시장 = 주차·교통, 팝업 = 대기·예약·운영 시간, 마트 = 가격, 맛집 = 가격·메뉴·웨이팅.
5. 글 길이는 1,100~4,800자로 우리 기준(1,200~3,200자)과 비슷 → 그대로.
