## 화면 구성 (10편 공통)

1. **첫 화면부터 "한 입 들어 올리기"**: 밥 위에 올린 고기·면을 집게·젓가락·숟가락으로 카메라 쪽으로 든다. 간판·외관·직원 컷으로 시작한 영상은 0편.
2. **거의 모든 컷에 손이 움직인다**: 자르기, 뒤집기, 부어주기(소스·육수), 소스 찍기, 쌈 싸기, 장갑 끼고 찢기. 그릇만 가만히 찍은 컷은 드물다.
3. 순서: 들어 올리기(훅) → 생고기 한 판 → 굽기(불·연기) → 자르기·찍어 먹기 → 곁들임(찌개에 밥 말기, 면, 볶음밥, 후식) → **마지막 컷 간판·외관·메뉴판** ("여기가 어디", 7편).
4. 넓은 컷은 1개 안팎 (내부 또는 외관), 사람 얼굴은 거의 없음 (1편만 먹는 표정).
5. 글자: 큰 제목보다 **작은 글자**. 위쪽에 친구 태그 한 줄("@고기 사줄 친구"), 말이 있으면 말 따라 바뀌는 작은 자막, 번호 목록형은 "1) 2) 3)" 이유.

## 촬영법 릴스 2편 (체크리스트에 반영)
- 음식 둘레 360도 돌기, 카메라를 30도쯤 기울여 위에서 천천히 내려오기, 휴지 위에 폰을 놓고 테이블에서 밀기(흔들림 없는 이동), 테이블 높이에서 낮게.

## 우리 앱에 반영한 것
- 맛집 스토리보드(`src/guides/storyboards.js`): 첫 컷 = 들어 올리기·시즐(간판·직원 시작 금지), 동작 비트 여러 컷, 곁들임·마무리 메뉴, 마지막 컷 간판·외관.
- 촬영 체크리스트(`src/guides/concepts.js`): 한 입 들어 올리기 2개(꼭), 손 동작 3개(꼭), 마무리 메뉴, 움직이며 찍기.
- 훅(`src/guides/stories.js`): 들어 올리기 + 친구 태그 한 줄.

## 아직 안 한 것
- 릴스 **"말 없이 음악 + 글자"** 형식 (인기 릴스의 절반): 지금은 모든 숏폼에 나레이션이 들어간다.
- 릴스는 컷을 더 빠르게(평균 1.2초): 쓸 수 있는 장면이 많아야 가능.
- 시험 자료(Pexels)에는 들어 올리기·손 동작 컷이 거의 없다 → 실제 가게 촬영에서 확인 필요.
