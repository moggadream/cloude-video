# 스토리보드·실제 자료 시험 작업 일지

> 사용량 한도로 멈췄다가 다시 시작할 때 **이 파일부터 읽고** 체크 안 된 첫 단계부터 이어서 한다.
> 요청 (2026-11-19): 텔레그램은 빼고, 인터넷에서 시험용 사진·영상을 모아 목표를 이룰 때까지 계속 만들기.
> - 글: 인기 글을 참고해 쓰는 법 지침을 계속 고친다.
> - 영상: 대본과 구도가 핵심. **스토리보드를 먼저** 만들어 인기 영상의 스토리보드와 대조하고, 비슷하게 만들 수 있을 때 영상을 만든다.
> - 카테고리(컨셉)마다 구도·스토리보드가 다르니 각각 지침을 만들고, 직접 영상을 만들어 다시 비교한다.

## 단계
- [x] 1. 인기 쇼츠 구조 조사 (컨셉 8개, 기본 브라우저로 영상 12등분 화면을 모아 분석) → `docs/research/storyboards.md`
- [x] 2. 컨셉별 스토리보드·구도 기준 `src/guides/storyboards.js` (비트 순서, 구도, 컷 길이, 이름표, 점수 매기기)
- [x] 3. 제작 과정: 분석에 구도(framing) 추가 → `makeStoryboard()` (75점 미만이면 고칠 점 주고 한 번 더) → 쇼츠·릴스·틱톡 대본이 스토리보드를 따름 (extra_shots = 빠른 컷, label = 이름표)
  - 렌더러: 화면 꽉 채우기(가로 사진은 옆으로 훑기, 가격표·간판은 전체), 한 나레이션 동안 여러 컷, 이름표 자막
  - 비교 도구: `node scripts/storyboard-sheet.js <작업ID>` → 만든 영상 12등분 화면 모음 + 컷 통계
  - 시험: `CONCEPT=mart SAMPLE_DIR=... node scripts/test-pipeline.js` (AI 없이는 `AI_MODE=off`)
- [x] 4. 시험 사진·영상 모으기: Pexels(무료·상업 이용 가능) 컨셉별 11~12개 → `tests/media/manifest.json`, 받기 `node scripts/fetch-test-media.js` (파일은 git 제외, 출처는 SOURCES.md). 위키미디어 공용은 한국 장소 영상이 거의 없어서 Pexels 로.
  - 컨셉 하나 시험: `SAMPLE_DIR=tests/media/<c> CONCEPT=<c> PLACE=... MEMO="$(cat tests/media/<c>/memo.txt)" node scripts/test-pipeline.js` → `node scripts/storyboard-sheet.js <작업ID>`
- [ ] 5. 컨셉별 실제 제작 → 스토리보드 일치도·장면 구도 비교 → 지침 고치기 (반복)
- [ ] 6. 기록 정리 (`docs/learning-log.md`), 커밋·push

## 진행 기록

### 1회차 (2026-11-20) 맛집 실제 제작
- 스토리보드 100점이었지만 완성 영상을 12등분 화면으로 보니: ① 같은 영상(m3)의 장면 3개가 연달아 나와 첫 9초가 한 컷처럼 보임 ② 음식 화면에 "테이블 간격 좁음" 자막(구도 안 맞는 컷을 억지로 채움) ③ "옷에 냄새 많이 뱀"으로 끝남.
- 고친 것: 같은 영상 연속·구도 불일치 25% 넘음·꼭 비트 빠짐은 **통과 불가(74점 상한)**, 비트 구도 맞음 점수 추가, 스토리보드 3번까지 다시, 렌더러가 같은 자료 컷을 번갈아 놓음, 마지막 비트는 팁으로(아쉬운 점은 팁 형태), 완성본 점검(실제 컷 길이·같은 자료 연속)을 화면 모음 도구에 추가.
- 글: 인기 쇼츠 제목 틀 6가지(개수 목록·가격 놀람·아는 사람만·끝판 정리·현장 질문·장소+느낌)를 쇼츠 스킬에.
- 다음: 맛집·카페·마트 다시 제작 (`node scripts/run-test-sets.js restaurant cafe mart`) → 시장·공원·유원지·축제·팝업.

### 2회차 (2026-11-20) 맛집·카페·마트
| 컨셉 | 스토리보드 | 쇼츠 완성본 | 화면 모음에서 본 문제 |
|---|---|---|---|
| 맛집 | 100 | 28초, 평균 3.2초 (기준 1~2.2) | 컷이 느림 |
| 카페 | 100 | 27초, 평균 2.7초 ✅ | 같은 짧은 영상(포크·케이크)을 4번 씀, 마지막 실내 컷 7초 정지 |
| 마트 | 74→89 | 34초, 평균 4.8초 (기준 2~3.5) | 번호 이름표 "1. 키위" "2. 귤" 잘 나옴, 마지막 걷는 컷 7초 |
- 원인: 스토리보드는 통과했는데 **대본 단계에서 나레이션이 길어지고, 스토리보드에 없는 같은 영상 컷을 더함**.
- 고친 것: 규칙 검사에 ① 같은 화면 반복(같은 영상 8초 안쪽) ② 컷이 기준의 1.4배 넘게 머무는 장면 → 2개 이상이면 오류 → 자동 보완이 고침. 스토리보드 점수도 같은 화면 반복을 통과 불가로. 장면 사이 같은 자료 연속도 렌더러가 피함.
- 다음: 맛집·카페·시장 다시 (`node scripts/run-test-sets.js restaurant cafe market`).

### 3회차 (2026-11-20) 맛집 (카페·시장은 사용량 한도로 중단)
- 맛집: 스토리보드 74 → 100 (같은 화면 반복으로 한 번 떨어지고 다시 짬), 쇼츠 22초·평균 2.5초 (3.2초에서 빨라짐), 첫 컷이 가게 외관 + 큰 제목 2줄.
- 화면 모음에서 본 문제: 한 장면에 컷이 여러 개인데 자막은 하나라 "뚝배기 계란찜 리필" 자막이 김치찌개 컷 위에도 뜸.
- 고친 것: **컷별 자막(cut_captions)** — 컷이 바뀌면 그 컷에 보이는 것의 이름으로 자막이 바뀜 (인기 맛집 쇼츠처럼 한 컷에 한 정보). 시험 도구가 사용량 한도에 걸리면 초기화 시각까지 기다렸다가 다시.
- 다음: `node scripts/run-test-sets.js cafe market restaurant` 그다음 `mart park amusement festival popup`.

### 4회차 (2026-11-24) 카페·시장 + 오픈소스 조사 + 움직이는 글자
- 카페: 스토리보드 100, 쇼츠 25.5초·평균 2.1초 ✅, 첫 컷 카페 전경 + 제목, 컷별 자막 잘 바뀜. 남은 문제: 초코 케이크 짧은 영상이 떨어진 자리에 3번.
- 시장: 스토리보드 81 (4컷, 가까운 컷 25%). 원인은 **시험 자료**: 꼬치·전 굽는 영상이 해외 시장(중국어 간판)이라 분석 AI가 "장소와 관계없음"으로 정확히 뺌. → 한국 길거리 음식 가까이 영상으로 시장 자료 교체 필요.
- 오픈소스 조사(`docs/research/open-source.md`) → Remotion 글자 층 + -14 LUFS 음량 적용 (`remotion/`, `src/pipeline/overlay.js`). 처음엔 글꼴이 안 먹은 줄 알았는데, 원본 크기로 비교하니 정상(작게 줄인 화면 때문에 착각).
- 다음: 시장 자료 교체(`tests/media/manifest.json`) → `node scripts/run-test-sets.js market mart park amusement festival popup`.

### 5회차 (2026-11-25) 영상 제작 도구 분석 세션 합치기
- 그 세션(rea-video 설치, 인기 맛집 쇼츠 4편 측정)이 이미 main 에 반영한 것: 첫 컷 길이·말 없는 장면 오류 → 자동 보완, 첫마디 의견·반전, **말 따라가는 자막**(4~9자 조각), 숏폼 목소리 +18%·쉬는 시간 축소·최소 장면 1.5초, 소리 끊김 수정(소리 먼저 만들고 합치기), 음성 앞뒤 무음 자르기.
- 그 세션에서 남은 문제 → 이번에 고침:
  1. **움직이는 글자가 자꾸 실패** → 원인: 조각마다 색 규격이 달라(아이폰 HDR=BT.2020 HLG, 사진=전체 범위 BT.601, 나머지 BT.709) 이어 붙인 영상을 Remotion 이 못 읽음. → 모든 조각을 BT.709 보통 범위로 통일, **HDR 영상은 톤 매핑**(zscale+tonemap). 실패하던 릴스가 Remotion 으로 성공, 아이폰 영상 색이 회색 → 원래 색.
  2. 분석용 장면 사진도 같은 색 변환 (AI 가 뿌연 HDR 화면을 보고 품질을 잘못 판단하지 않게, 블로그 사진도 선명해짐).
  3. 릴스 14초가 맛집 기준(15초)보다 짧다 → 인기 맛집 쇼츠가 13~60초라 기준을 12~45초로.
  4. 첫 화면 큰 글씨: 인기 영상은 화면 높이 20~40% → 제목 글씨 크기를 글자 수에 맞춰 최대(세로 최대 160px).
- 남은 것: 첫마디가 아직 인기 영상만큼 세지 않음, 가게 이름 위쪽 고정(스시 영상 방식)은 아직, 시장 시험 자료 교체, 나머지 컨셉 제작.
