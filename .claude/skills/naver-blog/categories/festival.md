## 축제·행사 후기

**검색하는 사람이 알고 싶은 것**: 언제까지·몇 시까지, 어디서·어떻게 가나(주차·셔틀), 뭐가 볼만한가(프로그램 시간), 먹거리·체험 가격, 얼마나 붐비나.

**제목 공식**: `[연도] [축제명] + [기간] + [주차·셔틀/프로그램] + 후기`
- 예: "2026 서창억새축제 11월 9일까지｜셔틀·주차 정리와 개막일 후기"
- 연도·기간은 필수.

**구성 (기본정보 먼저, 후기 나중)**
1. **한눈에 보는 기본 정보** (사진: 포스터) — 맨 앞에 목록으로: 기간, 운영시간, 장소, 입장료, 주차, 셔틀(노선·운행시간·막차). 포스터에서 읽은 것만.
2. **가는 법** (사진: 셔틀·주차 안내) — 주차장이 없거나 붐비면 대안까지.
3. **현장 분위기** (사진: 전경) — 방문 날짜·시간 기준 혼잡도.
4. **프로그램·공연** (사진: 무대·체험) — 시간표 순서로, 추천 동선.
5. **먹거리·부스** (사진: 먹거리+가격) — 가격 목록.
6. **꿀팁 + 아쉬운 점** — 화장실 줄, 그늘, 막차, 현금 등.
7. **마무리** — 기간을 다시 한 번 + 추천 대상.

**정확성 규칙**: 날짜·시간은 포스터·현수막에서 읽은 것만. 프로그램이 날짜별로 다르면 방문한 날 기준이라고 밝힌다. "운영 정보는 공식 홈페이지에서 한 번 더 확인하세요" 한 줄.
**분량**: 1,500~2,500자, 사진 10~15장.
**해시태그 예**: 축제명, 연도+축제명, 지역+축제, 지역+가볼만한곳, 가을축제/불꽃축제 등.
