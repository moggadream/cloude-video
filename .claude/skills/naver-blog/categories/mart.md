## 마트 할인·장보기 정보

**검색하는 사람이 알고 싶은 것**: 이번 주 무엇이 얼마나 할인인지, 언제까지인지, 회원 조건, 살 만한 것 추천.

**제목 공식**: `[마트명 지점] [기간] 할인 + [대표 품목] + 정리`
- 예: "코스트코 양재 11월 2주차 할인 정리｜체다치즈·베이컨·만두 가격"
- 연도·주차·날짜를 넣는다 (최신성이 생명인 정보).

**구성 (정보 정리형)**
1. **들어가며** — 방문 날짜, 무엇 위주로 봤는지, 할인 기간 공통점 한 줄.
2. **할인 폭 큰 순 BEST** (사진: 상품+가격표) — 3~5개를 먼저. "정가 → 할인가 (할인액), 기간".
3. **분야별 섹션** (먹거리 / 냉동·간편식 / 생활용품 / 가전 등) — 섹션당 사진 1~2장, 상품은 목록 형태로:
   `- 상품명 용량: 할인가 (−할인액, ~기간)` 
4. **조건 주의** — 회원 전용, 수량 한정, 기간이 다른 상품을 따로 모아서.
5. **내가 산 것 / 추천 TOP3** — 한 줄 이유와 함께 (메모 기준).
6. **방문 정보** — 지점, 영업시간, 주차, 붐비는 시간(메모).

**정확성 규칙**: 가격·기간은 가격표에 보이는 그대로. 읽히지 않으면 쓰지 않는다. 상품마다 기간이 다르면 반드시 표시.
**말투**: 정보 위주지만 "이건 냉동실 비워두고 가야 해요" 같은 한 줄 반응으로 사람 냄새.
**분량**: 1,500~2,500자, 사진 10~15장 (가격표 위주).
**해시태그 예**: 마트명, 마트명+지점, 마트명+할인, 이번주할인, 품목명(냉동만두 등), 장보기.
**흔한 실수**: 기간 누락, 할인 전/후 혼동, 회원 조건 누락.
