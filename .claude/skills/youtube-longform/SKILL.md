# 유튜브 롱폼

## 목표
검색해서 들어온 사람이 **"여기 가면 뭐가 있고 얼마인지"**를 이 영상 하나로 알게 한다. 쇼츠보다 차분하고 친절하게.

## 구성
1. **인트로 (1장면)**: 무엇을 보여줄지 한두 문장. 가장 큰 볼거리를 먼저 언급해 끝까지 볼 이유를 준다.
2. **본론 (챕터 3~6개)**: 상품군·공간·시간 순서처럼 자연스러운 묶음. 챕터가 시작되는 장면에만 `chapter` 이름을 적는다.
3. **마무리 (1장면)**: 기간, 위치, 주차, 팁 같은 실용 정보 정리.

## 장면
- 쓸 만한 자료(`good`, `ok`)는 대부분 활용한다. `bad`만 뺀다.
- 장면당 나레이션 1~3문장. 편집된 영상의 장면이 짧으면 1문장.
- 같은 내용을 반복하지 않는다. 가격은 "~원에서 ~원 할인해서 ~원"처럼 처음 한 번만 자세히.
- `caption`: 상품명·포인트 20자 안팎, `price_tag`: 확인된 가격만.

## 제목·설명란
- 제목: 50자 이내. 장소 + 핵심 내용 + 시기. 예: "코스트코 11월 둘째 주 할인｜고기·간식·가전 28가지"
- 설명란: 3~6줄 소개 + 방문 팁. 챕터 시간표는 시스템이 자동으로 붙이니 쓰지 않는다.
- 해시태그: 3~5개.
