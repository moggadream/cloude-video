# 🎬 cloude-video: 사진·영상으로 SNS 콘텐츠 자동 제작

마트·음식점·공원·행사장에서 찍은 사진과 영상을 넣고 텔레그램으로 "만들어줘"라고 하면, 플랫폼별 결과물 7종을 만들어 텔레그램으로 보고합니다. 승인하거나 고칠 점을 말하면 그대로 고쳐서 다시 보내 줍니다.

| 결과물 | 형태 |
|---|---|
| 유튜브 쇼츠 | 세로 1080×1920, 20~50초 |
| 인스타 릴스 | 세로 1080×1920, 10~30초 |
| 틱톡 | 세로 1080×1920, 15~45초 (화면 가림 영역을 피한 자막) |
| 유튜브 롱폼 | 가로 1920×1080, 챕터 포함 + 썸네일 1280×720 |
| 인스타 캐러셀 | 1080×1350 카드뉴스 5~10장 |
| 쓰레드 | 500자 이내 글 |
| 블로그 | 네이버 블로그 스타일 후기 + 사진 |

## 찍기 전에: 촬영 가이드

무엇을 만들지(컨셉) 고르면 **필요한 사진·영상 컷과 개수**를 알려줘요.

| 컨셉 | 전체 컷 | 꼭 필요한 컷 |
|---|---|---|
| 🍜 음식점·맛집 | 사진 15 · 영상 6 | 사진 5 · 영상 4 |
| ☕ 카페·디저트 | 사진 12 · 영상 4 | 사진 10 · 영상 2 |
| 🛒 마트 | 사진 21 · 영상 9 | 사진 18 · 영상 5 |
| 🏮 전통시장 | 사진 16 · 영상 8 | 사진 11 · 영상 4 |
| 🌳 공원·산책 | 사진 14 · 영상 5 | 사진 5 · 영상 2 |
| 🎡 유원지·테마파크 | 사진 9 · 영상 7 | 사진 2 · 영상 4 |
| 🎪 축제·행사 | 사진 14 · 영상 8 | 사진 8 · 영상 2 |
| 🎁 팝업스토어·전시 | 사진 11 · 영상 4 | 사진 10 · 영상 1 |

- 텔레그램 `/guide` → 컨셉 버튼 → 체크리스트
- 웹 홈 → 📋 가이드 → 컨셉 카드 → 찍으면서 체크
- 드라이브 폴더 이름 앞에 `[맛집]` `[카페]` `[마트]` `[시장]` `[공원]` `[유원지]` `[축제]` `[팝업]`을 붙이면 그 컨셉으로 만들어요 (없으면 텔레그램이 먼저 물어봐요)
- 가이드 원본: `src/guides/concepts.js`(컷 목록), `src/guides/stories.js`(콘텐츠 전략) → `node scripts/build-guides.js`로 스킬 문서 갱신

## 흐름

```
[나] 사진·영상 → 구글 드라이브 "업로드/<작업 이름>/" 폴더
[나] 텔레그램: "만들어줘" (또는 /make) → 폴더 고르기
        ↓  내 컴퓨터의 앱이 처리
  ① 자료 정리 (긴 영상은 장면 최대 60개 추출)
  ② AI 분석: 장소 종류, 상품·메뉴·가격, 행사 시간, 장면 품질   ← 스킬: content-analyze
  ③ 플랫폼별 대본·글 (각각 따로, 컨셉 전략·블로그 카테고리 작성법 반영) ← 스킬: youtube-shorts 등 7개 + humanize-korean + concept-*
  ③-1 자체 검증: 규칙 검사 + AI 편집장 채점(6개 항목) → 기준 미달만 자동 보완 ← 스킬: content-review
  ④ 영상·카드뉴스·썸네일 제작 (자막, 가격 표시, 음악)
  ⑤ 드라이브 "결과/<작업 이름>/" 에 저장
        ↓
[텔레그램] 영상·이미지·글 + ✅승인 ✏️수정 ⏸보류 버튼
[나] ✏️ 누르고 "첫 장면 딸기로, 자막 더 짧게" → 그 결과물만 고쳐서 다시 보고
```

- 앱은 **요청할 때만** 일합니다. 드라이브 폴더를 계속 지켜보지 않아요.
- 텔레그램 확인은 앱이 텔레그램에 새 메시지를 물어보는 방식이라 **공개 주소나 포트 열기가 필요 없고, AI 토큰도 들지 않아요.**
- 50MB 넘는 영상(주로 롱폼)은 텔레그램 대신 드라이브 링크 버튼으로 알려 줍니다.

## 처음 설정 (한 번만)

1. **Node.js 20 이상, ffmpeg** 설치 (PowerShell에서 `node -v`, `ffmpeg -version`으로 확인)
2. 프로젝트 폴더에서 `.env.example`을 복사해 `.env`로 이름 바꾸기
3. **텔레그램 봇 만들기**
   - 텔레그램에서 `@BotFather` 검색 → `/newbot` → 이름 정하기 → 받은 토큰을 `.env`의 `TELEGRAM_BOT_TOKEN=`에
   - 앱을 켜고 내 봇에게 `/start` → 알려주는 채팅 ID를 `TELEGRAM_CHAT_ID=`에 → 앱 다시 켜기
4. **구글 드라이브 연결**
   - [구글 드라이브 데스크톱](https://www.google.com/drive/download/) 설치·로그인 → 드라이브가 `G:` 같은 드라이브로 보임
   - 드라이브에 작업용 폴더(예: `콘텐츠자동화`)를 만들고 `.env`의 `DRIVE_DIR=`에 위치 적기
   - 앱을 한 번 켜면 그 안에 `업로드`, `결과` 폴더가 생겨요. 드라이브 웹에서 `결과` 폴더를 열고 주소창 주소를 `DRIVE_RESULT_URL=`에
5. **AI**: 내 컴퓨터에 Claude Code가 로그인돼 있으면 **자동으로 사용**해요 (`claude --version`으로 확인). API 키를 넣으면 API를 우선 사용.
6. `start-windows.bat` 더블클릭

## 자료 올리는 법

- 드라이브 `업로드` 폴더 안에 **작업 하나당 폴더 하나**
  - 폴더 이름 = 장소 이름 (예: `코스트코 양재점`)
  - 앞에 `[마트]` `[맛집]` `[행사]`를 붙이면 장소 종류를 알려줄 수 있어요
  - 폴더 안에 `메모.txt`를 넣으면 메모로 써요 (방문 이유, 영업시간, 행사 기간 등. **사진으로 알 수 없는 맛·후기도 여기에**)
- 20MB 이하 사진은 텔레그램 봇에게 바로 보내도 돼요

## 텔레그램 명령

| 명령 | 하는 일 |
|---|---|
| `/make` 또는 "만들어줘" | 만들 폴더 고르기 |
| "코스트코 만들어줘" | 이름에 "코스트코"가 들어간 폴더로 바로 시작 |
| `/list` | 최근 작업 (누르면 결과 다시 받기) |
| `/status` | AI·드라이브 연결 상태 |
| ✏️ 수정 버튼 / 결과 메시지에 답장 | 그 결과물만 말한 대로 고치기 |

## "내 말투"로 쓰게 하기

- 프로젝트 폴더의 `style-samples/` 또는 드라이브 작업 폴더의 `말투샘플/`에 예전에 쓴 블로그 글, 유튜브 대본, 인스타 캡션을 `.txt`로 넣어 두세요. 그 말투를 닮게 씁니다.
- 텔레그램으로 요청한 수정 내용은 `data/feedback.jsonl`에 쌓이고, 다음 대본을 쓸 때 취향으로 반영돼요.

## 스킬 (플랫폼별 작성 규칙)

`.claude/skills/` 아래 문서를 고치면 다음 제작부터 바로 반영돼요. 같은 폴더에서 Claude Code를 쓰면 Claude Code도 이 스킬을 씁니다.

| 스킬 | 역할 |
|---|---|
| `content-analyze` | 자료 분석 (사실만, 장면 품질) |
| `content-review` | 자체 검증 채점 기준 |
| `shoot-guide`, `concept-*` (8개) | 컨셉별 촬영 체크리스트 + 콘텐츠 전략 |
| `humanize-korean` | AI 티 안 나는 한국어 (모든 플랫폼 공통) |
| `youtube-shorts`, `youtube-longform` | 유튜브 |
| `instagram-reels`, `instagram-carousel` | 인스타그램 |
| `tiktok`, `threads`, `naver-blog` | 틱톡, 쓰레드, 블로그 (`naver-blog/categories/` 9종 카테고리 작성법) |

## 자체 검증과 학습

- 만들 때마다 결과물별 점수(🧪)가 텔레그램·웹에 표시돼요. 기준(총점 4.3, 모든 항목 4점 이상) 미달이면 자동으로 한 번 고쳐 써요.
- 끄려면 `.env`에 `REVIEW=off`. 기준 바꾸기: `REVIEW_THRESHOLD=4.0`
- 평가 시나리오로 스킬 품질을 시험: `node scripts/eval-scenario.js restaurant festival park` → `docs/evals/`
- 지금까지 배운 것과 고친 것: [`docs/learning-log.md`](docs/learning-log.md), 조사: [`docs/research/`](docs/research/)

## 구조

```
src/
  server.js            웹 확인 화면 + API, 텔레그램 봇 시작
  telegram/bot.js      텔레그램: 만들기·승인·수정 지시, 결과 보고
  drive.js             드라이브 업로드 폴더 읽기, 결과 폴더 저장
  ai/index.js          AI 연결 (API 키 / 내 컴퓨터 Claude Code / 테스트 모드)
  ai/skills.js         스킬 문서, 말투 샘플, 수정 기록 읽기
  pipeline/
    index.js           전체 흐름, 수정 요청 반영
    plan.js            분석 → 플랫폼별 대본 → 수정
    render.js          영상 (줌, 흐림 배경, 자막, 가격 표시, 컷 경계 맞춤)
    carousel.js        카드뉴스 이미지
    texts.js           플랫폼별 올릴 글
    media.js / audio.js
.claude/skills/        플랫폼별 스킬 문서
```
